Server setup

The public RootMC server is already connected. This page is for staff configuring the Paper plugins on the host.

Plugin configuration

On the game host, set cloud credentials in plugins/RootMC/cloud.yml and tune plugins/RootMC/rootmc.yml. Jars are deployed to the host directly — not published on this site yet.

  • cloud.server-id and cloud.server-secret — from the RootMC API (staff only)
  • cloud.stats-url-base — https://rootmc.net/player
  • server.map-url — https://map.rootmc.net/
